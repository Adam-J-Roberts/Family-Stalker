# Security

This project is pre-implementation and has not been audited. Do not rely on it for sensitive location sharing yet.

Please do not post real coordinates, household details, credentials, or exploit secrets in public issues. Use GitHub's private vulnerability reporting if the repository owner has enabled it. If unavailable, ask for a private reporting route without publishing exploit details.

The private reporting channel, supported versions, response targets, and release security policy must be configured before public deployment. No supported production release exists today.

See [the draft security model](docs/security-model.md) for intended protections and limits.
